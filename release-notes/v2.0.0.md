Coax v2.0.0 — first NHA release: Angular renderer, signed builds, zero telemetry

The first release built and published by National Heritage Academies. Everything v2.0 and up ships from this repo; the 1.x line was the upstream Melodic Development project.

- **Renderer rewritten in Angular 21** — same UI and workflow, now on the stack NHA teams use everywhere else. Along the way: a proper loading indicator while requests are in flight, a fix for the Headers/Body tabs showing stale content when switching between request tabs, and assorted polish.
- **Signed and notarized installers** — the Windows installer is Authenticode-signed by *National Heritage Academies, Inc.* and the macOS build is notarized under NHA's Apple Developer account. No more SmartScreen/Gatekeeper warnings.
- **Telemetry removed entirely** — the upstream opt-in crash reporting is gone. The app's only network traffic is the requests you send and the update check (which you can turn off in Settings).

**Note for 1.x users:** v2.0.0 has a new app identity, so Melodic-era installs will not auto-update into it — download the installer for your platform below and install fresh. From 2.0.0 onward, updates arrive automatically.
